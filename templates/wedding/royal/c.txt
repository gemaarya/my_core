Sirf 2 cheezein fill karni hain code mein:
1️⃣ GOOGLE_FORM_ID nikalo
Apni Google Form ka URL kuch aisa hoga:
https://docs.google.com/forms/d/e/1FAIpQLSe_ABCDEF123.../viewform
Bas 1FAIpQLSe_ABCDEF123... wala part copy karo aur yahan paste karo:
jsconst GOOGLE_FORM_ID = '1FAIpQLSe_ABCDEF123...';

2️⃣ entry.XXXXXXXXX IDs nikalo — yeh kaise karte hain:

1)Apni Google Form kholo
2)3-dot menu (⋮) → "Get pre-filled link" click karo
3)Har field mein kuch bhi type karo (jaise "test")
4)Neeche "Get Link" click karo → link copy karo

Link kuch aisa dikhega:
https://docs.google.com/forms/d/e/FORM_ID/viewform?
  entry.123456789=test       ← Name ka entry ID
  &entry.987654321=test      ← Mobile ka entry ID
  &entry.111222333=test      ← Email ka entry ID
  ... aur baaki fields

  Har entry.XXXXXXXX number ko copy karke code mein paste karo:
jsconst FORM_ENTRIES = {

  guests    : 'entry.444555666',
  functions : 'entry.777888999',
  dietary   : 'entry.000111222',
  blessing  : 'entry.333444555',
